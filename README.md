# PerspectiveFix

**PerspectiveFix** is a free online perspective image correction tool that helps you fix skewed and distorted images directly in your browser.

🌐 **Live Demo:**  
https://oathanrex.github.io/perspective-fix/

---

## 🚀 What is PerspectiveFix?

PerspectiveFix allows you to straighten and correct perspective distortion in images such as:

- Scanned documents
- Book pages
- Whiteboards
- Architectural photos
- Posters
- Screenshots

All processing happens **locally in your browser** — your images are never uploaded to any server.

---

## ✨ Features

- ✅ Free to use
- 🔒 100% privacy-friendly (browser-based)
- ⚡ Real-time live preview
- 🖼️ Supports PNG, JPG, and WebP
- 📐 Manual corner-based perspective correction
- 🚫 No watermark
- 📥 Full-resolution downloads

---

## 🛠️ How It Works

1. Upload an image (drag & drop or click)
2. Adjust the four corner points to match the distorted area
3. Preview the corrected result instantly
4. Download the corrected image
